# AGENTS.md

## Sobre o projeto

**clone-tabnews-ia** é um caso de estudo para "clonar" o [TabNews](https://www.tabnews.com.br/) — fórum de tecnologia criado pelo Filipe Deschamps — utilizando IA como ferramenta de desenvolvimento. O formato segue a linha do curso.dev, que usa o clone do TabNews como fio condutor.

## Stack

- **Next.js** com App Router (código em `app/`)
- **React**
- Idioma do site: `pt-BR`

## Scripts

```bash
npm run dev    # servidor de desenvolvimento
npm run build  # build de produção
npm run start  # servidor de produção
```
